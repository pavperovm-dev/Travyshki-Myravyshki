# Травушки-Муравушки

Консольная игра на C#. МуравейSON собирает травушки (*) и приносит их в логово (H) до кровавой зимы.
Враги: жук (B) и паук (S). Оружие (!) делает муравьяSON сильнее.

## Запуск
cd TravushkiMyravushki
dotnet run

## Управление
w / a / s / d - идти, h - покушать травушку (лечение), q или exit - выход.
Сложность в начале: легко / средне / сложно.

## Версии
- v0.1 - прототип: поле, состояние, ввод, расчёт урона.
- v0.2 - игровой цикл while, if-else if-else, switch, границы мира, победа и поражение.

## Как воспроизвести сценарии (сложность "легко", поле всегда одинаковое)
1. Сбор травушки: ввести  d, d  -> на втором шаге "Нашёл травушку!", травинки 1/3, счёт 10.
2. Бой с жуком: ввести  d, d, d, s  -> бой с жуком, HP 20 -> 16, счёт 25.
3. Лечение: после сценария 2 ввести  h  -> HP 20, травинок 0.
4. Граница мира: в начале ввести  a  или  w -> "Левый край МИРА!" / "Верхний край МИРА!", ход не тратится.
5. Неизвестная команда: ввести  abc  -> "Такой команды нет, муравейSON запутался.".
6. Победа: ввести  d d s s a s s a w w w w  (по одной команде за раз) -> ПОБЕДА! Логово сыто, кровавая зима не страшна!, счёт 30.
7. Поражение: выбрать "сложно", ввести  d d d s  (жук), затем  d d d s  (паук, HP 4),
   затем  a a a s s s  (второй паук) -> ПОРАЖЕНИЕ. МуравейSON погиб в бою...
8. Выход: в любой момент ввести  q  -> "МуравейSON ушёл далеко. До встречи!" и итоговый счёт.
